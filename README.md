# CHat Information, Knowledge Analytics, Visualization Overviewer

Streamlit-приложение для глубокой аналитики Telegram-чата: активность, медиа, реакции, слова и многое другое в одном ёмком дашборде.

## Возможности

- 🌙 Полностью переработанный тёмный интерфейс с акцентами и адаптивной версткой.
- 📊 Семь вкладок с интерактивными визуализациями: сводка, активность, медиа, текст, реакции, доп.инсайты и данные.
- 🕒 Хитмэп активности по дням недели и часам, показатели «любимого формата» и динамика сообщений по месяцам.
- 📁 Поддержка различных типов сообщений (текст, фото, видео, стикеры, голосовые, файлы) с цветовой кодировкой.
- 🔤 Анализ слов и эмодзи с учётом стоп-слов на русском и английском.

## Быстрый старт

1. **Создайте экспорт чата** в Telegram Desktop (`Настройки → Дополнительно → Экспорт данных Telegram`) и выберите формат JSON.
2. **Установите зависимости через [uv](https://github.com/astral-sh/uv)**:

    ```shell
    uv sync
    ```

3. **Запустите приложение** в изолированной среде uv:

    ```shell
    uv run streamlit run main.py
    ```

4. **Загрузите экспортированный JSON** через интерфейс и изучайте дашборд.

## Навигация по дашборду

- **Сводка** – ключевые показатели, «любимый» тип сообщений и интерактивные бейджи с пиковыми периодами.
- **Активность** – динамика сообщений, хронология по часам, тепловая карта «день недели × час» и сравнение годов.
- **Медиа** – распределение типов медиа и их тренды по месяцам, детальные панели по голосовым и видео.
- **Текст** – топ отправителей, длина сообщений, гистограмма распределения и частотные слова.
- **Реакции** – любимые эмодзи-реакции и пользователи, которые ставят их чаще всего.
- **Дополнительно** – статистика по стикерам, эмодзи и словарю.
- **Данные** – таблица первых 100 строк и кнопка скачивания CSV.
